# Лабораторная работа 2, задание 3: Структуры данных в C

## Overview
Данный проект создан в учебных целях для изучения структур в языке 
программирования C.

## Author
Юрченко Александра, группа 10

## Usage
1. Клонировать репозиторий:
git clone git@github.com:fpmi-tpmp2026/tpmp-lab2-task3.git

2. Перейти в папку проекта:
cd tpmp-lab2-task3

3. Скомпилировать программу:
make

4. Запустить программу:
./program
